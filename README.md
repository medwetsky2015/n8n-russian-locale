# n8n-russian-locale

Русская локализация интерфейса [n8n](https://n8n.io).

n8n поставляется **только с английским интерфейсом**. Переменная `N8N_DEFAULT_LOCALE=ru`
сама по себе ничего не даёт: загрузчик локалей не находит русского словаря и откатывается
на английский. Этот проект добавляет русский словарь в сборку n8n.

## Что переведено

| Часть | Строк |
|---|---|
| Основной интерфейс (редактор, настройки, узлы, проекты, оценки) | 8 769 |
| Панель AI-ассистента (отдельный мини-словарь) | 246 |
| Связанные сообщения (`@:_reusableBaseText.*`) | 24 |
| Улы и credentials (854 юнита) | 37 233 |
| Имена узлов (`headers.js`) | 428 |
| **Всего строк** | **20 354** |

Переведено всё, что имеет смысл переводить. Непереведёнными осознанно оставлены
API-идентификаторы, имена продуктов (`n8n AI`, `OpenAI`, `Vector Stores`),
технические значения (camelCase/snake_case) и шаблоны из одних плейсхолдеров (`{date}, {time}`).

## Установка

Нужен Node.js (тот же, которым запускается n8n).

```bash
git clone https://github.com/medwetsky2015/n8n-russian-locale.git
cd n8n-russian-locale

# посмотреть, что будет сделано, ничего не меняя
node apply.js --dry-run

# применить
node apply.js
```

Скрипт сам находит каталог `n8n-editor-ui/dist/assets`. Если n8n установлен
нестандартно, укажите путь явно:

```bash
node apply.js --dist /путь/к/n8n-editor-ui/dist/assets
```

Затем задайте локаль и перезапустите n8n:

```bash
export N8N_DEFAULT_LOCALE=ru
```

Чтобы переменная сохранялась между сессиями, добавьте её в `~/.zshrc` (или `~/.bashrc`):

```bash
echo 'export N8N_DEFAULT_LOCALE=ru' >> ~/.zshrc
```

> Файл `~/.n8n/.env` n8n **не читает автоматически** — переменную нужно задать
> в окружении процесса.

## Docker

Патчить нужно внутри контейнера, а чтобы изменение пережило пересоздание —
вынести пропатченные файлы на хост и примонтировать.

```bash
# 1. скопировать установщик в контейнер
docker cp apply.js <контейнер>:/tmp/
docker cp ru.json <контейнер>:/tmp/
docker cp ru-mini.json <контейнер>:/tmp/

# 2. применить внутри контейнера (файлы принадлежат root)
docker exec -u 0 <контейнер> node /tmp/apply.js

# 3. скопировать пропатченные файлы на хост
docker cp <контейнер>:/usr/local/lib/node_modules/n8n/node_modules/n8n-editor-ui/dist/assets/<main>.js ./ru-patch/
docker cp <контейнер>:/usr/local/lib/node_modules/n8n/node_modules/n8n-editor-ui/dist/assets/<loader>.js ./ru-patch/
```

Затем добавьте в `compose.yaml` переменную и монтирование:

```yaml
services:
  n8n:
    environment:
      N8N_DEFAULT_LOCALE: "ru"
    volumes:
      - ./ru-patch/<main>.js:/usr/local/lib/node_modules/n8n/node_modules/n8n-editor-ui/dist/assets/<main>.js:ro
      - ./ru-patch/<loader>.js:/usr/local/lib/node_modules/n8n/node_modules/n8n-editor-ui/dist/assets/<loader>.js:ro
```

> Имена файлов содержат хеш содержимого и меняются между версиями n8n —
> подставьте свои. `apply.js` печатает их при запуске.

**Важно:** `docker cp` на примонтированный путь **заменяет inode**, и контейнер
продолжает читать старый файл. Пишите содержимое на месте и пересоздавайте контейнер:

```bash
docker cp <контейнер>:/tmp/patched.js /tmp/patched.js
sudo sh -c "cat /tmp/patched.js > /path/in/mount.js"
docker compose up -d --force-recreate n8n
```

## Откат

```bash
node apply.js --restore
```

Скрипт хранит оригиналы в `.backup/` и возвращает их. После отката перезапустите n8n.

## Как это работает

n8n использует [vue-i18n](https://vue-i18n.intlify.dev/). В сборке есть два места,
куда нужно внедрить перевод:

1. **Основной бандл** — файл, содержащий `messages:{en:C}`. Это весь словарь
   интерфейса и вызов `createI18n`.
2. **Загрузчик мини-словаря** — файл, содержащий `"./lang/en.ts"`. Это отдельный
   маленький i18n для панели AI-ассистента; его карта динамических импортов знает
   только английский.

Скрипт находит оба файла **по содержимому** (имена содержат хеш и меняются
между релизами), затем:

- добавляет правило плюрализации для русского в вызов `createI18n`;
- добавляет словарь `ru` рядом с `en`;
- добавляет `"./lang/ru.ts"` в карту импортов загрузчика.

### Плюрализация

Правило vue-i18n по умолчанию английское, поэтому без доработки выходило
«1 Папки», «2 Папок». В проект добавлено русское правило (3 формы + четвёртая
для «нулевого» состояния), и все 116 счётных сообщений приведены к правильным формам:

```
1 папка · 2 папки · 5 папок · 21 папка
1 пользователь · 2 пользователя · 5 пользователей
```

## Обновление n8n

Патч живёт в файлах сборки, поэтому **при обновлении n8n он теряется** — новые
бандлы приходят с новыми хешами. После обновления просто запустите `apply.js` снова:

```bash
node apply.js
```

Скрипт проверяет синтаксис **до** записи и отказывается работать, если структура
бандла изменилась — так вы не получите сломанный интерфейс.

## Совместимость

Проверено на n8n **2.41.6**. Словарь привязан к набору ключей этой версии: на других
версиях переведётся то, что совпало по ключам, остальное останется английским
(это безопасно — vue-i18n откатывается на `en`).

## Участие

Правки перевода приветствуются: правьте `ru.json` / `ru-mini.json` и присылайте PR.
Ключи менять нельзя — только значения.
